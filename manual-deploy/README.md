# 직접 배포용 갤러리

- `index.html`: 미술 체험실을 제거한 갤러리. 필요한 로컬 코드, 작품 이미지 매핑, 미술관 배경을 포함한 단일 HTML 파일입니다.
- Firebase 인증/조회/좋아요/댓글과 외부 작품 이미지는 인터넷 연결이 필요합니다. 실제 교실 환경과 Firebase 권한은 별도 확인해야 합니다.
- 기존 수업용 `index.html`과는 다른 파일입니다. 기존 `hongji33/artmind2` 수업 페이지를 유지하면서 갤러리만 갱신하려면 이 파일을 **`metaverse.html`로 이름을 바꿔 업로드**하세요.
- 별도 사이트의 시작 페이지로 쓰는 경우에는 `index.html`이라는 이름으로 배포할 수 있습니다.
- 자동 병합/배포하지 않았습니다. 이 브랜치의 파일을 내려받아 직접 배포합니다.
- 단일 파일 구문 및 Chromium 모의 Firebase 회귀 검사 통과: 이동/문/벤치/원단/표정/감상 기록/호버/좋아요/댓글 및 체험실 제거.


## 학생 로그인/로그아웃

승인된 닉네임 옆에 로그아웃 버튼을 추가했습니다. 실제 익명 계정 로그아웃은 기존 UID로 돌아오지 못할 수 있으므로 안내 후 확인/취소합니다. 로그아웃 후에는 새로고침해도 자동 로그인하지 않으며, 다음 학생이 학생 로그인 버튼을 눌러 진입합니다. 새 UID에는 교사 학급 승인이 다시 필요할 수 있습니다.

반 비밀번호/교사별 관리 화면은 아직 포함하지 않았습니다. 기존 Firebase 수동 승인 구조를 유지합니다.
