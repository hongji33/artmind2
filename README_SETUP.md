# 마음의 미술관 — 현재 사용 안내

## 학생

1. 교사가 보여 주는 반별 QR을 찍거나 학생 링크를 엽니다. 기본 주소만 전달하면 담당 교사 공간이 지정되지 않을 수 있으므로 반별 주소를 사용합니다.
2. 학년·반·닉네임·4자리 반 비밀번호로 입장합니다.
3. 감정을 고르고 한국·서양 작품 중 한 점을 선택합니다. 이미지가 로드된 작품만 선택할 수 있습니다.
4. 눈으로 관찰하기 → 마음으로 느끼기 → 나를 돌아보기를 작성하고, 감상문과 제목을 다듬습니다.
5. ‘① 내 감상문 저장’ → 공개 내용 확인 → ‘② 전시하고 메타버스 입장’을 누릅니다. 온라인 저장 성공 후 미술관으로 이동합니다.
6. 전시 후 첫 화면으로 돌아오면 상단 ‘미술관으로 돌아가기’로 재게시 없이 입장합니다.
7. 같은 반 작품을 감상하고 같은 관의 친구 캐릭터에게 정해진 인사 버튼으로 인사합니다. 전시관은 자유롭게 선택하며 특별 전시관은 같은 쪽의 친구만 보입니다.

## 저장

작성 중인 감상문은 이번 활동의 임시 자료이며 새로고침·로그아웃 전에 필요하면 파일로 내려받습니다. 온라인 전시 저장은 Firebase Firestore에 보관되며 같은 반 학생과 담당 교사가 볼 수 있습니다. 로그아웃은 이미 게시한 전시를 삭제하지 않습니다. 익명 학생이 새로 로그인하면 UID가 바뀔 수 있어 이전 전시의 수정 권한을 자동 복원하지 않습니다.

## 교사

‘교사용’에서 이메일 계정을 만들거나 로그인합니다. 담당 반과 반 입장 번호를 설정하고 ‘입장 QR’을 모니터에 띄우거나 ‘링크 복사’로 전달합니다. ‘학생 화면 열기’는 학생 입장 화면을 새 탭으로 엽니다. ‘미술관 보기’는 교사 계정으로 담당 반을 바로 관람하며 학생용 감상문이나 반 비밀번호가 필요하지 않습니다. 반별 작품은 확인·숨김·다시 전시할 수 있습니다.

## 기기와 범위

크롬북에서는 방향키/WASD와 E 또는 클릭으로 이동·감상합니다. 휴대폰에서는 방향 버튼으로 이동하고 전시관 위를 세로로 밀어 페이지를 스크롤합니다. 직접 업로드한 캐릭터·원단은 해당 기기에만 적용됩니다. 자유 채팅·음성 채팅·자동 영상 제작은 제공하지 않습니다.

Firestore는 회원·반 설정·전시·댓글을, Realtime Database는 실시간 위치와 인사를 담당합니다. 운영 규칙은 각각 별도로 게시합니다. 교사의 실시간 관람에는 최신 Realtime Database 규칙이 필요합니다. 실제 기기 연결과 무료 사용량은 운영 환경에서 확인해야 합니다. Apps Script 설치는 이 웹앱의 제출 절차가 아닙니다.
