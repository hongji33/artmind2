# 마음의 미술관 — Firebase 연결 시범판

프로젝트: artmind2-2edd4

## 교사 설정 (필수)
1. Firebase 콘솔 > Authentication > 로그인 방법에서 **익명** 인증을 사용 설정합니다.
2. Firebase 콘솔 > Firestore Database를 만들고 `firestore.rules`의 내용을 규칙에 붙여 넣어 게시합니다. 기존 프로젝트에 규칙이 있다면 **전체 덮어쓰기 금지**: 기존 규칙과 병합해야 합니다.
3. GitHub Pages에 index.html을 배포합니다. `file://`로 실행하지 마세요.
4. 학생이 앱을 처음 열면 온라인 갤러리 워크 영역에 익명 로그인 UID가 나타납니다. 교사는 Firestore 콘솔에서 `artmind2_members/{UID}` 문서를 직접 만들고 필드 `classId` (문자열, 예: `1-1`), `nickname` (문자열, 예: `푸른별`)을 넣습니다. 승인 전에는 온라인 기능을 사용할 수 없습니다.
5. 승인된 학생이 학년·반을 동일하게 입력하고 감상문을 작성해 로컬 저장한 뒤 '나의 미술관 온라인 전시하기'를 누르면 게시됩니다. QR은 생성된 링크로 연결됩니다.

## 제한 사항
- **현재는 시범판입니다.** 학급 승인 작업이 교사 수동 방식이므로 학급 전체 사용에 앞서 일괄 등록용 관리자 기능이 필요합니다.
- 익명 인증은 기기/브라우저가 바뀌거나 저장 정보가 삭제되면 UID가 바뀔 수 있습니다. 실제 수업에서는 학교 계정 인증이나 재로그인 가능한 인증 방식으로 바꾸는 것이 좋습니다.
- 학생이 온라인에 게시한 감상문은 같은 반 승인 학생에게 공개됩니다. 교사가 삭제/숨김 처리할 수 있는 관리 화면은 아직 없습니다. 교사는 Firebase 콘솔에서 댓글을 삭제할 수 있습니다.
- QR은 링크를 제공할 뿐이며, 학급 접근 제한은 Firestore 규칙으로 처리합니다.
- 작품 이미지는 기존 HTML의 외부 이미지 출처를 사용합니다. QR로 들어온 친구 기기에서는 작품 이미지를 찾지 못할 수 있으므로 이미지 저장소 연결이 추가로 필요합니다.
- 실제 Firebase 콘솔에 인증·규칙을 적용하거나 배포하지 않았습니다. 브라우저에서 실서버 동작도 검증하지 않았습니다.
- 다른 Firebase 앱의 데이터를 보호하기 위해 `artmind2_*` 컬렉션만 사용합니다. 기존 Firestore 규칙은 반드시 병합하세요.
