# 교사 계정과 반 관리

교사는 미술관의 **교사용** 버튼에서 이메일 아이디·비밀번호로 로그인합니다. 관리자 화면에서 자신의 반 생성/설정, 4자리 학생 번호 일괄 저장, 반별 작품 보기·숨김·복원을 처리합니다. 교사별 반과 작품은 별도의 공간에 보관합니다. 기존 기기는 이메일 계정 연결로 기존 자료를 이어받습니다.

- [교사 사용 안내](TEACHER_SETUP.md)
- [운영자 최초 설치와 검증](DEPLOYMENT.md)
- [Firestore 보안 규칙](firestore.rules)
- [실시간 캐릭터와 교사 관람 설정](REALTIME_SETUP.md)

교사 관리·학생 반 입장·온라인 전시·실시간 캐릭터 기능을 제공합니다. 인증 제공자와 운영 규칙은 설치 환경에서 적용해야 하며, 실시간 교사 관람에는 최신 Realtime Database 규칙이 필요합니다. 교사에게 UID 등록이나 콘솔 이동을 요구하는 이전 절차는 새 관리자 화면에서 사용하지 않습니다.

Spark를 유지하며 Cloud Functions를 사용하지 않습니다. 반 번호 4자리는 공동 입장용이며, 학생별 개인번호 6자리는 같은 계정으로 재로그인하는 데 사용합니다. 닉네임은 반 안에서 중복 등록할 수 없습니다. 무료 쿼터 소진 시 서비스가 중단될 수 있고, 기존 익명 학생은 로그아웃 후 같은 닉네임으로 이전 작품 수정 권한을 복구하지 않습니다. 게시한 학생 자료는 삭제하지 않습니다.

`password-setup.html`과 `firestore-private.fragment.rules`는 이전 설치 방식의 참고 자료입니다. 새 설치에는 전체 규칙을 사용하고, 교사의 번호 설정은 관리자 화면에서 합니다.
