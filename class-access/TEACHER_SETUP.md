# 교사가 직접 반 비밀번호 저장·변경하기

무료 Spark를 유지합니다. 학생 비밀번호는 숫자 4자리이며 `1111`, `0123` 모두 가능합니다. 학생 개인 인증 대신 공동 입장 번호로 사용합니다.

## 최초 한 번: 관리자 설정

이미 교사 화면에서 비밀번호 저장을 사용 중이라면 다시 설정할 필요가 없습니다. 표 방식 변경에는 추가 규칙 게시가 필요하지 않습니다.

1. 이 버전의 `firestore.rules` 전체를 Firebase 콘솔 → Firestore Database → 규칙 탭에서 게시합니다. 기존 작품·댓글·좋아요 규칙은 그대로 유지했습니다. 교사 역할을 학생이 스스로 만들거나 담당 반을 바꿀 수 없습니다.
2. 교사 관리 화면이 배포된 뒤 교사용 기기에서 `teacher.html`을 열고 **교사 기기 연결**을 누릅니다. 표시되는 **교사 ID**를 복사합니다. 학생 익명 로그인과는 다른 Firebase 앱의 세션을 사용합니다.
3. Firebase 콘솔 → Firestore Database → 데이터에서 `artmind2_teachers` 컬렉션에 문서를 만듭니다. 문서 ID는 방금 복사한 교사 ID입니다.

| 필드 | 유형 | 예시 |
|---|---|---|
| enabled | boolean | true |
| classIds | array | string `3-1`, string `3-2` |

4. 교사 화면으로 돌아와 **승인 확인**을 누릅니다. 담당 학반 목록이 나타납니다. 다른 교사는 그 교사의 기기 ID로 별도 문서를 만들고 해당 교사 담당 반만 지정할 수 있습니다.

## 이후: 사이트에서 번호 변경

담당 반이 표로 표시됩니다. 변경할 반에만 새 번호를 입력한 뒤 **입력한 반 한 번에 저장**을 누릅니다.

| 반 | 새 비밀번호 |
|---|---|
| 3-1 | 1111 |
| 3-2 | 2222 |

빈칸인 반은 번호와 입장 허용 설정 모두 기존 값이 유지됩니다. 번호를 입력한 행에 대해서만 ‘새 입장 허용’ 선택도 함께 저장합니다. 입력한 모든 반의 공개 salt와 비공개 해시를 한 일괄 쓰기로 함께 저장합니다. 실패하면 성공으로 표시하지 않고 입력값을 남겨 다시 시도할 수 있습니다. 성공하면 입력칸을 비웁니다. 원문 비밀번호를 서버/브라우저 저장소에 보관하지 않으며, 기존 번호를 조회하는 기능은 없습니다.

비밀번호 변경은 새 학생 입장부터 적용됩니다. 이미 입장한 학생의 세션과 게시된 작품은 유지합니다. 담당 반을 늘리거나 교사 권한을 회수하려면 관리자 콘솔에서 해당 교사 문서를 변경합니다.

## 기기와 계정

교사 연결은 익명 UID에 교사 역할을 부여하는 방식입니다. 교사용 기기에서만 연결하세요. 연결 해제 또는 브라우저 데이터 삭제 후에는 같은 ID로 복구하지 못할 수 있어 새 교사 ID를 관리자 콘솔에 다시 등록해야 합니다. 학생 로그인/로그아웃 버튼은 이 교사 연결을 변경하지 않습니다.

## 검증 범위

교사 UI의 승인 대기, 담당 반 목록, 두 반 번호의 일괄 저장·빈칸 유지·0123 변경, 4자리 검증, 저장 실패 시 입력 유지, 학생 세션과 다른 앱 사용을 모의 SDK Chromium으로 검사합니다. 실제 Firebase 보안 규칙 실행 및 학교 환경의 동시 접속은 별도 검증이 필요합니다. 규칙 에뮬레이터 다운로드는 현재 실행 환경의 네트워크 정책에 막혀 실행하지 못했습니다.
