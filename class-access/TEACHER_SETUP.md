# 교사 사용 안내

## 처음 이용할 때

미술관 첫 화면의 **교사용** → **처음이라면 교사 계정 만들기**를 누릅니다. 표시 이름, 이메일 아이디, 교사 비밀번호를 입력하면 내 관리자 화면이 열립니다. 교사 비밀번호는 8자 이상이며 학생의 반 번호(숫자 4자리)와 별개입니다. 이후 같은 이메일과 비밀번호로 다른 기기에서도 로그인합니다. 비밀번호를 잊으면 로그인 화면에서 재설정 메일을 요청합니다.

기존 기기로 반과 작품을 관리하던 교사는 그 브라우저에서 계정을 만들면 기존 UID에 이메일 자격을 연결하여 기존 반·작품을 이어받습니다. 이미 다른 UID에 연결된 이메일 계정으로 기존 자료를 자동 합치지는 않습니다. 원래 기기 연결을 먼저 해제하거나 브라우저 자료를 지우지 않습니다.

## 관리자 화면

- **반 추가**: 학년·반, 표시 이름, 처음 학생 번호 4자리를 입력합니다. 다른 교사의 같은 이름 반과 별도 공간에 만들어집니다.
- **내 반 설정**: 반 이름·입장 허용 여부·새 번호를 표에서 바꾸고 한 번에 저장합니다. 빈 번호는 기존 번호를 유지합니다. 기존 반의 학년·반 식별자는 작품 보존을 위해 고정합니다.
- **입장 QR**: 해당 반의 QR을 열어 전체 화면으로 보여 줍니다. 학년·반이 크게 표시되며 학생이 카메라로 찍어 입장합니다.
- **링크 복사 / 학생 화면 열기**: 반별 링크를 복사해 전달하거나 학생 입장 화면을 새 탭으로 엽니다. 학생은 교사가 공유한 링크에서 학반·닉네임·4자리 번호로 입장합니다.
- **반 보관/복원**: 보관하면 새 입장을 막고 목록에서 숨기며 작품은 보존합니다. 보관한 반 표시를 켜면 복원할 수 있습니다. 예전 방식으로 만든 기존 반에는 ‘입장 중지’를 제공합니다.
- **반별 작품 관리**: 반을 선택하여 작품과 감상문을 확인하고 갤러리 숨김/다시 전시를 선택합니다. 이는 갤러리 표시 관리이며 원본과 댓글·좋아요를 삭제하지 않습니다. 이미 공개한 자료의 비밀 접근 회수 기능은 아닙니다.

교사는 Firebase 콘솔, 기기 ID 등록 또는 별도 승인 절차를 거치지 않습니다. 서비스 최초 설치 작업은 운영자 안내에 별도로 정리했습니다.

## 미술관 관람

교사는 담당 반의 ‘미술관 보기’로 감상문 없이 바로 입장합니다. 학생은 감상문을 작성하고 온라인에 전시한 뒤 입장합니다. 교사는 작품을 관람하고, 최신 실시간 규칙 적용 후 같은 갤러리 학생 캐릭터도 읽기 전용으로 볼 수 있습니다. 교사 계정을 학생 회원으로 등록하거나 학생 인사를 보내지 않습니다.

## 갤러리 배치

담당 반의 ‘갤러리 배치’에서 개방형/T자/U자/파티션 배치를 골라 저장합니다. 모두 한 공간이며 학생을 별도 관으로 나누지 않습니다. 접속 중인 학생에게도 반영되므로 수업 전에 배치를 정하는 것이 좋습니다. 새 좌표·디자인·배치 저장을 허용하는 실시간 규칙은 운영자가 한 번 게시합니다.
